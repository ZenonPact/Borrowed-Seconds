# Borrowed Seconds

An Unreal Engine 5.8 game-jam project built around physics interaction and time pressure.

## Requirements

- Unreal Engine 5.8
- Visual Studio 2022 with the **Game development with C++** workload
- Git LFS

## Getting started

1. Clone the repository.
2. Run `git lfs pull`.
3. Right-click `BorrowedSeconds.uproject` and select **Generate Visual Studio project files**.
4. Open `BorrowedSeconds.uproject` in Unreal Editor.

Generated folders (`Binaries`, `DerivedDataCache`, `Intermediate`, and `Saved`) and packaged builds are intentionally not stored in Git.

## Controls

- Move: WASD
- Look: Mouse
- Jump: Space
- Grab/release/reset: configured through the Enhanced Input assets in `Content/Input`
